## Build the editor's copy

Run `make` with Git, GNU Make, `kramdown-rfc`, and `xml2rfc` on your
path. See the [Internet-Draft Template setup guide][setup] for installation
details. The Makefile loads a pinned revision of that template. It generates
HTML and plain-text copies next to the source and lints the draft. Keep the
generated files out of Git.

Successful builds on `main` publish the HTML and plain-text copies to
GitHub Pages. Pull requests build and lint without publishing. Each
successful build also provides an `editor-copy` artifact.

Publishing an editor's copy does not submit it to the IETF. For formal
submission, follow the [IETF Datatracker instructions][submit].
