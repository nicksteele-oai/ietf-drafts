## Build the editor's copy

Run `make` with Git, GNU Make, `kramdown-rfc`, and `xml2rfc` on your
path. See the [Internet-Draft Template setup guide][setup] for installation
details. The Makefile loads a pinned revision of that template. It generates
HTML and plain-text copies next to the source and lints the draft. Keep the
generated files out of Git.

On GitHub, open a successful **Build editor's copy** run and download the
`editor-copy` artifact to view the HTML or plain text. Access is restricted to
people with repository access. No workflow deploys a website or submits a draft.

## Publish later

Review the public draft and the Git history before changing repository
visibility. An editor's copy on GitHub Pages and formal submission to the IETF
are separate, opt-in steps. To set up Pages when ready, use the
[template's setup guide][setup]. To submit the initial `-00`, prepare a
numbered draft from the editor's source, validate it, and follow the
[IETF Datatracker submission instructions][submit]. Neither step is enabled
here.
