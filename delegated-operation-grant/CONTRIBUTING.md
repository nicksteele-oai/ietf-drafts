# Contributing

Use an issue for protocol design questions and a pull request for proposed
text changes. Explain how a change affects the platform, workload, authorization server,
or resource server. For changes to enforcement, include an example of a
request that should pass and one that should fail.

Edit the [Markdown source](draft-steele-oauth-delegated-operation-grant.md)
and run `make` before requesting review. Do not commit rendered files, secrets,
or nonpublic examples that cannot travel with the draft.

For material submitted to the IETF,
see [BCP 78](https://www.rfc-editor.org/info/bcp78),
[BCP 79](https://www.rfc-editor.org/info/bcp79), and the
[IETF Trust Legal Provisions](https://trustee.ietf.org/trust-legal-provisions.html).
